# แชทบอทส่วนตัวใน LINE 💬

แชทบอทที่คุยแบบตัวต่อตัวใน LINE Official Account — เจ้าของเขียนคำสั่งเองว่าให้บอทเป็นใคร รู้ข้อมูลอะไร ตอบแบบไหน แล้วบอทจะคุยตามนั้น ใช้เป็น **แอดมินตอบลูกค้า** หรือ **เลขาส่วนตัว** ก็ได้ และเจ้าของคุมทุกอย่างได้จากแชท LINE

![ตัวอย่างบทสนทนา: ลูกค้าสั่งของ บอทคิดยอด · ส่งสลิป บอทอ่านยอด · เจ้าของถามสรุปและแก้ราคาผ่านแชท](docs/images/demo.png)

<sub>ร้านสมมติ "บ้านมะลิ" · ข้อความในภาพเป็นคำตอบจากระบบจริง</sub>

**เริ่มยังไงดี**
- 🤖 **ให้ AI พาติดตั้ง** — ก๊อปพรอมต์ใน [AI-SETUP.md](AI-SETUP.md) ไปวางใน Claude Code หรือ Codex แล้วตอบคำถามไปทีละข้อ
- 📖 **ติดตั้งเอง** — [INSTALL.md](INSTALL.md) ทีละขั้น ประมาณ 30–45 นาที ไม่ต้องเขียนโปรแกรมเป็น

## ทำอะไรได้บ้าง

**คุยกับลูกค้า**
- **ทำหน้าที่ตามคำสั่งของเจ้าของ** — ไฟล์ `brief.txt` บอกว่าบอทคือใคร รู้อะไร (สินค้า ราคา เวลาเปิด นโยบาย) ตอบแบบไหน ห้ามทำอะไร
- **ไม่เดา** — ข้อมูลที่ไม่ได้เขียนไว้ บอทบอกว่าไม่ทราบ · เลขบัญชีหรือเบอร์โทรที่ไม่มีในข้อมูลจริงจะถูกตัดทิ้งก่อนถึงลูกค้า
- **จำบทสนทนาของแต่ละคน** — คุยต่อจากเมื่อกี้ได้ ถาม "สรุปที่คุยกัน" ก็สรุปให้
- **อ่านทุกอย่างที่ส่งมา** — 🖼️ รูป สลิป เมนู ฉลาก · 🎤 ข้อความเสียง · 🎬 วิดีโอ · 📄 PDF / txt / csv · 😺 สติกเกอร์ · 📍 ตำแหน่ง
- **ทักทายเอง** ตอนมีคนแอดเพื่อน · ขึ้นจุด "กำลังพิมพ์..." ระหว่างคิด

**โหมดเจ้าของ** 👑 — เจ้าของพิมพ์รหัสลับหาบอทครั้งเดียว แล้วคุยกับบอทแบบผู้ช่วยส่วนตัว
- ถามเรื่องลูกค้า: "วันนี้ใครสั่งอะไรบ้าง" "ใครส่งสลิปมา ยอดตรงไหม" "สรุปแชทคุณพลอย" "มีใครถามเรื่องที่บอทตอบไม่ได้"
- แก้หน้าที่บอทผ่านแชท: "แก้ราคาคุกกี้เป็น 130" หรือส่งรูปเมนูใหม่มา → บอทโชว์จุดที่จะเปลี่ยน → พิมพ์ `ยืนยัน` ใช้ทันที (`ย้อนกลับ` ได้)
- `ทดลองเป็นลูกค้า` เพื่อลองคุยแบบที่ลูกค้าเห็น · ไม่โดนเพดานข้อความต่อวัน

**แบบหน้าที่พร้อมใช้ 7 ธุรกิจ** ใน [`briefs/`](briefs/) — ร้านออนไลน์ · ร้านอาหาร · หอพัก · ร้านเสริมสวย · คอร์สเรียน · ช่างบริการถึงบ้าน · เลขาส่วนตัว — เลือกแบบที่ใกล้ที่สุด แก้ช่อง `〔...〕` ให้เป็นข้อมูลจริง จบ

**รันได้ 2 ที่** — Railway (ง่ายสุด) หรือ Vercel + Turso — โค้ดชุดเดียวกัน ดูวิธีใน [INSTALL.md](INSTALL.md)

## ข้อจำกัด

- คุยได้เฉพาะแชทส่วนตัว — ถ้ามีคนเชิญเข้ากลุ่ม บอทบอกสั้นๆ แล้วออกเอง
- บอทคุยได้อย่างเดียว ทำงานนอกแชทไม่ได้ (ยืนยันออเดอร์ ตัดสต็อก ลงนัด โอนเงิน) และไม่ยืนยันว่า "ได้รับเงินแล้ว" จากสลิป — บอกได้แค่ว่าได้รับสลิปและร้านจะตรวจยอด
- ทักหาคนก่อนไม่ได้ ตอบเมื่อมีคนทักมา
- จำบทสนทนาย้อนหลังได้ราว 6,000 ตัวอักษรล่าสุดของแต่ละคน · รายงานโหมดเจ้าของดูย้อนหลัง 7 วัน

## ต้นทุน

| รายการ | ค่าใช้จ่าย |
|---|---|
| ตอบแชท 1 ข้อความ | ~฿0.05–0.15 (ขึ้นกับความยาวของ brief.txt และบทสนทนา) |
| อ่านรูป เสียง วิดีโอ | +~฿0.04–0.1 ต่อชิ้น |
| เจ้าของถามสรุป 1 ครั้ง | ~฿0.1–0.3 |
| ส่งข้อความกลับใน LINE | ฟรี (ตอบกลับด้วย reply) |
| ที่รันบอท | Railway ~$5/เดือน · Vercel ใช้ทำธุรกิจต้องแพ็กเกจ Pro $20/เดือน (Hobby ฟรีแต่ห้ามใช้เชิงพาณิชย์) · Turso ฟรี |

กันค่า AI บานด้วย `DAILY_LIMIT` — ข้อความสูงสุดต่อคนต่อวัน (ค่าเริ่มต้น 100) · ค่าเริ่มต้นใช้ `google/gemini-2.5-flash` ผ่าน OpenRouter เปลี่ยนได้ที่ `AI_MODEL` / `VISION_MODEL`

## ลองก่อนติดตั้งจริง

```bash
npm install
npm test                              # เทส offline ไม่ต้องต่อเน็ต — ต้องขึ้น "0 พัง"
cp briefs/online-shop.txt brief.txt   # เลือกแบบหน้าที่ แล้วแก้ช่อง 〔...〕
npm run chat                          # คุยกับบอทใน Terminal (ต้องมี OPENROUTER_API_KEY ใน .env)
```

## โครงสร้างโค้ด

```
src/app.js        แอป Express: /webhook /health /admin/backup (ใช้ร่วมกันทั้ง Railway และ Vercel)
src/index.js      เปิดเซิร์ฟเวอร์ปกติ (Railway / เครื่องตัวเอง)

src/bot.js        รับ event จาก LINE: ทักทาย / ตอบลูกค้า / โหมดเจ้าของ / อ่านสื่อ / ออกจากกลุ่ม / เพดานต่อวัน
src/owner.js      โหมดเจ้าของ: รหัส รายงานแชทลูกค้า คำสั่ง ยืนยัน/ย้อนกลับ จุดที่เปลี่ยนในคำสั่ง

src/brief.js      คำสั่งประจำตัว: อ่านไฟล์ เก็บทุกฉบับ ซ่อนช่อง 〔...〕 ที่ยังไม่กรอกจากลูกค้า
src/guard.js      ด่านกันเลขบัญชี/เบอร์โทรที่ AI แต่งขึ้นเอง
src/db.js         ฐานข้อมูล libSQL: ไฟล์ในเครื่อง หรือ Turso บนคลาวด์
src/media.js      อ่านรูป เสียง วิดีโอ PDF แล้วคืนเป็นข้อความ
src/branding.js   ชื่อบอท คำแทนตัว อิโมจิ คำลงท้าย
briefs/           แบบหน้าที่พร้อมใช้ 7 ธุรกิจ
scripts/try-chat.js  คุยกับบอทใน Terminal
```

## ความเป็นส่วนตัว

บอทเก็บบทสนทนาและชื่อ LINE ของคนที่คุยด้วยลงฐานข้อมูลของผู้ติดตั้งเอง ไม่ได้ส่งให้ใครนอกจากผู้ให้บริการ AI ที่ใช้ตอบ — ควรแจ้งคนที่คุยด้วยว่ากำลังคุยกับบอทและมีการเก็บบันทึก

ใครรู้ `OWNER_CODE` เข้าโหมดเจ้าของและอ่านแชทลูกค้าได้ · ใครถือ `ADMIN_KEY` ดาวน์โหลดฐานข้อมูลได้ — ตั้งให้ยาวและอย่าแชร์ · ถ้า fork repo นี้ไปใส่ข้อมูลร้านจริง ให้ตั้งเป็น **Private**
