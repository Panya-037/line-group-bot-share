# บอทเลขากลุ่ม LINE 📝

เชิญเข้ากลุ่ม LINE แล้วบอทจะจดแชทให้ทั้งวัน สรุปงานให้ตอนเย็น ค้นเรื่องเก่าให้ได้ และอ่านทุกอย่างที่ส่งเข้ากลุ่ม — รวมถึงสลิป เสียงพูด และไฟล์

**ตั้งชื่อบอทเองได้** ตั้งชื่อในไฟล์ `.env` ค่าเดียว แล้วการ์ดในกลุ่ม คำตอบของ AI และหน้าแดชบอร์ดจะใช้ชื่อนั้นทั้งหมด

👉 **เพิ่งได้ไฟล์มา เริ่มที่ [INSTALL.md](INSTALL.md)** — คู่มือติดตั้งทีละขั้นตั้งแต่ตั้งชื่อบอทจนบอทเข้ากลุ่มได้จริง

---

## ทำอะไรได้บ้าง

- **เก็บบันทึกแชท** ลงฐานข้อมูลในเครื่องตัวเอง ทุกข้อความ ค้นย้อนหลังได้ด้วย `!ค้น <คำ>`
- **อ่านทุกอย่างที่ส่งเข้ากลุ่ม** (ทำงานเบื้องหลัง ไม่หน่วงกลุ่ม)
  - 🖼️ รูป → อธิบาย + ถอดข้อความ/ตัวเลขในรูป (สลิป เอกสาร แชทแคป กระดานงาน) — กลุ่มที่สั่ง `!อ่านรูป เปิด` บอทจะสรุปตอบกลับในกลุ่มทันที
  - 🎤 เสียงพูด → ถอดเป็นข้อความ
  - 🎬 วิดีโอ → ดึงเฟรมแรกมาอธิบาย
  - 📄 ไฟล์ txt/csv/json/md/pdf → อ่านเนื้อหา 2,000 ตัวอักษรแรก
  - 😺 สติกเกอร์ → จดอารมณ์ · 📍 ตำแหน่ง → จดชื่อ+ที่อยู่
  - ทุกอย่างกลายเป็นข้อความในบันทึก → ค้น/สรุป/ถามต่อได้เหมือนแชทปกติ
- **สรุปงานรายวันอัตโนมัติ** ส่งเข้ากลุ่มตอน 20:00 (ปรับได้รายกลุ่ม) เป็นการ์ดตาราง **งาน | ใคร | กำหนด** พร้อมหมวดเงินและเรื่องค้าง — คัดเฉพาะเรื่องงาน ตัดคุยเล่นทิ้ง
- **ดักจับยอดเงิน** อัตโนมัติจากทั้งข้อความและสลิปที่ AI ถอดมา (`!ยอดเงิน`)
- **ตอบคำถามจากประวัติแชท** — `!ถาม <คำถาม>` หรือ @ ชื่อบอทแล้วถามได้เลย
- **แดชบอร์ดสำหรับหัวหน้า** — กรองตามช่วงเวลา/กลุ่ม สรุปผลเป็นประโยคภาษาคน และการ์ด ✅ **งานที่ต้องทำ** รวมทุกกลุ่มไว้บนสุด
- **หน้าภาพรวมรายกลุ่ม** — เปิดทีเดียวเห็นว่าวันนี้แต่ละกลุ่มคุยอะไรกันบ้าง เลือกย้อนดูรายวันได้
- คนกดลบข้อความ (unsend) → บอทลบบันทึกนั้นตาม

**ข้อจำกัดของ LINE:** บอทเห็นเฉพาะข้อความ *หลังจาก* เข้ากลุ่มเท่านั้น ไม่มีช่องทางอ่านประวัติย้อนหลัง

## คำสั่งในกลุ่ม

| คำสั่ง | ทำอะไร |
|---|---|
| `!ช่วย` | ดูคำสั่งทั้งหมด |
| `!สรุป` / `!สรุปเมื่อวาน` | สรุปแชทวันนี้ / เมื่อวาน แบบละเอียด |
| `!ค้น <คำ>` | ค้นข้อความย้อนหลัง 10 รายการล่าสุด |
| `!ถาม <คำถาม>` | ถาม AI จากประวัติแชท |
| `!ยอดเงิน` | ตัวเลขเงินที่จับได้วันนี้ |
| `!อ่านรูป เปิด/ปิด` | ส่งรูปแล้วให้บอทสรุปตอบทันที (ค่าเริ่มต้นปิด — ปิดอยู่ก็ยังอ่านเก็บเงียบๆ) |
| `!สรุปอัตโนมัติ เปิด/ปิด` | เปิด/ปิดสรุปรายวันของกลุ่มนั้น |
| `!เวลาสรุป <0-23>` | ตั้งชั่วโมงส่งสรุป (เวลาไทย) |

ตอบในกลุ่มใช้ reply token = **ฟรี ไม่จำกัด** มีแต่สรุปรายวันอัตโนมัติที่เป็น push (กินโควต้าฟรีของ LINE 300 ครั้ง/เดือน — วันไหนแชทเงียบบอทข้ามให้เอง)

## ตั้งชื่อ / แต่งหน้าตาบอท

ทุกอย่างอยู่ในไฟล์ `.env` ไฟล์เดียว แก้แล้วรีสตาร์ทหนึ่งครั้ง:

```ini
BOT_NAME=น้องมะลิ      # ชื่อบอท — โผล่ในการ์ด คำตอบ AI และหน้าแดชบอร์ด
BOT_SELF=น้อง          # คำแทนตัวเอง (ไม่ตั้งก็ได้ ระบบเดาจากชื่อให้)
BOT_THEME=green        # โทนสี: sky | pink | green | purple | orange
BOT_EMOJI=💚           # อิโมจิประจำตัว (ไม่ตั้ง = ตามธีม)
BOT_POLITE=ชาย         # ใส่เมื่อต้องการให้ลงท้าย "ครับ" แทน "ค่ะ"
```

การเดาคำแทนตัวเอง: ชื่อขึ้นต้น "น้อง" → เรียกตัวเองว่า *น้อง* · ขึ้นต้น "พี่" → *พี่* · ชื่ออื่น → เรียกชื่อตัวเองเต็ม

โค้ดทุกไฟล์อ่านชื่อและสีจาก [`src/branding.js`](src/branding.js) ที่เดียว — จะเพิ่มธีมสีใหม่ก็แก้ไฟล์นั้นไฟล์เดียว

## หน้าแอดมิน

| ที่อยู่ | ใช้ทำอะไร |
|---|---|
| `/admin?key=ADMIN_KEY` | แดชบอร์ดหลัก — ฟิลเตอร์ช่วงเวลา/กลุ่ม, สรุปผลเป็นภาษาคน, การ์ดงานที่ต้องทำ, กราฟ, ยอดเงิน |
| `/admin/overview?key=` | ภาพรวมรายกลุ่ม — การ์ดต่อกลุ่มบอกว่าวันนั้นคุยอะไรกันบ้าง ใครคุยเยอะ เลือกดูย้อนวันได้ |
| `/admin/report?key=` | อ่านสรุปแชทวันนี้ทุกกลุ่มแบบเต็ม (ดูเอง ไม่ส่งเข้ากลุ่ม) |
| `/admin/summary?key=&group=<id>` | พรีวิวการ์ดสรุปของกลุ่มนั้น (เติม `&send=1` = ส่งเข้ากลุ่มจริง, `&date=YYYY-MM-DD` = เลือกวัน) |
| `/admin/backup?key=` | ดาวน์โหลดไฟล์ฐานข้อมูลไว้สำรอง |
| `/health` | เช็คว่าบอทยังมีชีวิต |

การ์ด "งานที่ต้องทำ" ใช้ผลที่คัดไว้แล้วเป็นหลัก — ไม่มีข้อความใหม่เข้ามาก็ไม่เรียก AI ซ้ำ เปิดหน้าซ้ำกี่รอบก็ไม่เสียเงินเพิ่ม (ปุ่ม "อ่านใหม่" คือสั่งให้อ่านสดจริงๆ)

## ต้นทุน

| รายการ | ค่าใช้จ่าย |
|---|---|
| ข้อความปกติในกลุ่ม | ฟรี (ไม่เรียก AI) |
| สรุปรายวัน / `!สรุป` / `!ถาม` | ~฿0.02–0.1 ต่อครั้ง |
| อ่านรูป เสียง วิดีโอ | ~฿0.04–0.1 ต่อชิ้น |
| ตอบในกลุ่ม | ฟรีไม่จำกัด (reply token) |
| สรุปอัตโนมัติ push เข้ากลุ่ม | กินโควต้าฟรีของ LINE 300 ครั้ง/เดือน |

ค่าเริ่มต้นใช้ `google/gemini-2.5-flash` ผ่าน OpenRouter (ถูกและเร็ว) เปลี่ยนรุ่นได้ที่ `AI_MODEL` / `VISION_MODEL`

## ลองเล่นก่อนโดยไม่ต้องมีกลุ่มไลน์

```bash
npm install
cp .env.example .env    # ตั้งแค่ ADMIN_KEY ก็พอ
npm run demo            # ใส่ข้อมูลตัวอย่าง 2 กลุ่ม แล้วเปิดเซิร์ฟเวอร์
```

เปิด `http://localhost:3000/admin?key=<ADMIN_KEY>` จะเห็นแดชบอร์ดพร้อมข้อมูลจำลอง (ชื่อ ยอดเงิน ข้อความ ทั้งหมดเป็นของสมมติ)

รันเทสแบบไม่ต้องต่อเน็ต: `npm test` (75 เคส — ครอบคลุมชื่อ/ธีม/คำลงท้าย, ฐานข้อมูล, คำสั่ง, การ์ด, แคชงานที่ต้องทำ, ฟิลเตอร์แดชบอร์ด, หน้าภาพรวม)

## โครงสร้างโค้ด

```
src/branding.js   ชื่อบอท คำแทนตัว อิโมจิ โทนสี — ที่เดียวที่กำหนดตัวตนบอท
src/index.js      webhook + หน้าแอดมิน + จุดเริ่มโปรแกรม
src/db.js         SQLite: groups / members / messages / extracts / pushes / work_items / digests
src/commands.js   คำสั่งในกลุ่ม (!สรุป !ค้น !ถาม ...)
src/tasks.js      คัด "งานที่ต้องทำ" + แคชผล AI ต่อ (กลุ่ม, วัน)
src/digest.js     สรุปว่าแต่ละกลุ่มคุยอะไรกันในวันนั้น (แคชแบบเดียวกับ tasks.js)
src/summary.js    ตัวตั้งเวลาสรุปรายวัน + สำเนาเข้า Telegram
src/ai.js         เรียก AI ผ่าน OpenRouter (สรุป / ตอบคำถาม / คัดงาน)
src/media.js      อ่านรูป เสียง วิดีโอ ไฟล์ แล้วเขียนกลับเป็นข้อความ
src/flex.js       การ์ด Flex ทุกใบ
src/dashboard.js  หน้าแดชบอร์ด + ภาพรวมกลุ่ม + หน้าอ่านสรุป
src/extract.js    ดักจับยอดเงินด้วย regex
src/lineapi.js    เรียก LINE API ส่วนที่ SDK ไม่มีให้
src/time.js       เวลาโซนไทย
bin/backup-db.sh  ดึงไฟล์ฐานข้อมูลมาเก็บไว้ในเครื่อง (เก็บ 14 วัน)
```

ดูภาพรวมการทำงานแบบเป็นแผนภาพที่ [WORKFLOW.md](WORKFLOW.md)

**หมายเหตุสำหรับคนดูแลระบบ:** บน Railway ตัว builder คือ Railpack — ไฟล์ `nixpacks.toml` ไม่มีผล ถ้าต้องการ ffmpeg (อ่านเสียง/วิดีโอ) ให้ตั้ง env `RAILPACK_DEPLOY_APT_PACKAGES=ffmpeg`

## ความเป็นส่วนตัว

บอทเก็บข้อความและชื่อสมาชิกในกลุ่มลงฐานข้อมูลของผู้ติดตั้งเอง ไม่ได้ส่งให้ใครนอกจากผู้ให้บริการ AI ที่ใช้สรุป — **ควรใช้กับกลุ่มงานที่สมาชิกรับทราบแล้วว่ามีบอทจดบันทึกอยู่** ชื่อสมาชิกจะดึงได้เฉพาะคนที่เปิดโปรไฟล์ให้บอท คนอื่นแสดงเป็น "ไม่ทราบชื่อ"

ใครถือ `ADMIN_KEY` เปิดดูแชททั้งหมดได้ — ตั้งให้ยาวและอย่าแชร์
